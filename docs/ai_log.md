1. "경기도 읍면동 경계와 연령별 인구, 버스정류장 위치를 결합해 300m 보행권 비율과 최근접 정류장 평균거리를 계산하고, 결합 누락과 인구 합계를 검증해줘"

3. "DRT 차량 종류별로 자가용 대비 탄소 손익분기 동승 인원을 가정값을 공개하는 방식으로 계산해줘"
4. "공모 서식 항목 순서대로 본문 5장 내외 분석보고서 초안을 작성하고, 모든 수치는 산출 표에서만 가져와줘"

## 참가자 검증 내용
- 읍면동 인구 합계(13,777,186명) = 경기도 총인구 일치 (`outputs/tables/prep_log.csv`)
- 경계·인구 결합 누락 0건, 남양주시 화도읍 출장소 2곳 합산 처리 확인
- 취약도 상위 지역이 지도상 실제 산간·농촌 지역인지 대조
- 보고서 본문 수치를 `outputs/tables/*.csv`와 대조

## 입력 자료와 이용 조건
- 입력: 공공데이터포털·주민등록 인구통계·admdongkor의 공개 자료와 그 집계 결과, 이 저장소의 코드
- 개인정보·개인위치정보·영업비밀·비공개 자료는 입력하지 않음
- 서비스의 데이터 보관·학습 활용·제3자 제공 조건을 확인함. 입력 자료가 모두 공개 자료이므로 공개 범위가 넓어지지 않음

## AI가 하지 않은 것
- 데이터 값의 생성·보완·대체 없음. 탄소 계수는 '가정값'으로 명시하고 `outputs/tables/carbon_assumptions.csv`에 공개
